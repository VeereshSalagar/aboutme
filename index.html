About Me

I am a Software Test Engineer with 4+ years of experience in software quality assurance, test automation, and Verification & Validation. My primary focus is building reliable and maintainable automated tests using Playwright with TypeScript.

My automation experience includes Playwright with TypeScript, Selenium with Java, API testing, Appium, SQL, Cucumber, TestNG, Git/GitHub, and CI/CD with GitHub Actions. I have worked across functional, regression, integration, system, API, mobile, and mission-critical application testing.
